# 自动化操作范围

| 入口 | 身份与操作 |
|---|---|
| 日历助手 | 在选中的一本或多本日历查询与修改日程、预览和确认批量操作。取消全选会停用发送。 |
| 账号助手 | 以个人账号确认创建日历、创建团组、接受邀请。首次建日历也可使用。 |
| 安卓设备助手 | 使用本机命令配置两个组件、同步和处理冲突；需要系统交互的权限由手机用户授予。 |
| CLI、MCP 和机器人 | 可使用个人会话或限权令牌。日历操作权限取当前日历授权与令牌范围的交集，账号操作要求个人会话。 |
| 独立后台 | 管理账号、授权、实例模型、备份及安卓发布。后台 API、CLI 和 MCP 使用独立的管理员会话。 |
